
一、小优化
Easytyping：自动格式化，例如句首输入英文时，首字母自动大写；中英文混合输入时，中文和英文之间自动添加空格。Done

Recent files：显示最近打开过的文件。Done

Setting search：在设置的地方搜索关键词，可以看到所有跟这个关键词相关的设置。 Done

二、大功能
Readitlater：类似 b 站的稍后再看；

React Components组件：嵌入 react 组件，比如生日倒计时功能。

Kanban：看板，有很多小卡片来展示待办、正在处理的任务，同时还可以和其他的笔记进行绑定；

Tasks：任务收集，感觉比较复杂，暂时可以先不了解；

MAKE. Md：一系列功能的子集，开启后整个界面会变化，变成了不一样的软件；（初学阶段暂不开启，等后续熟练以后再开启使用）


三、美观化
Commander：添加各种定制快捷键；（初学阶段暂不开启，等后续熟练以后再开启使用）

Iconize：给文件夹定制并添加图标，右键文件夹，选择 change icon/remove icon 即可；

Style settings：外观主题设置；（初学阶段暂不开启，等后续熟练以后再开启使用）

Mood tracker：心情追踪及记录，可以给每篇日记添加一个心情图标，并在 mood tracker history 里展示每天的心情记录；

Banners：obsidian 文档里添加头图


四、软件联动
Weread：和微信读书联动，展示书本中的各种笔记；

Zotero：管理文献，做学术研究可能比较需要；

滴答清单、todoList 等，几乎可以联动所有软件；
