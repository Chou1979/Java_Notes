> > 脑子里一定要有一个会动的图：
> > 1）代码在运行的时候，起码有一个 main 线程会去执行所有的代码，当然也可能是你启动的别的线程；
> > 2）线程执行时必须通过自己的程序计数器来记录执行到哪一个代码指令了；
> > 3）线程在执行方法时，为每个方法都得创建一个栈帧放入自己的 Java 虚拟机栈里去，里面有方法的局部变量；
> > 4）最后就是代码运行过程中创建的各种对象，都是放在 Java 堆内存里的。
